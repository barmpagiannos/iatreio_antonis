# iatreio_antonis

## Run locally

1. Install the Python dependency:

   ```bash
   pip install -r requirements.txt
   ```

2. Start the Flask development server:

   ```bash
   python app.py
   ```

3. Open [http://127.0.0.1:5000](http://127.0.0.1:5000).

Available pages:

- `/`
- `/profile`
- `/services`
